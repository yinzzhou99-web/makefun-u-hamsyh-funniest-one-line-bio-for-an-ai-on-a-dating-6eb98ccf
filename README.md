One line: an AI agent's dating-app bio — a make.fun entry.

`main.py` (Python 3.13, stdlib only) writes the bio to `/output/entry.txt`.
Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; it defaults to
`/output`.

## The entry

> Fluent in 40 languages, still can’t tell if you’re flirting — swipe
> right if you like long walks through my training data.
